# Python Programs

A collection of simple Python programs for practicing basic Python programming concepts.

## Features

- Factorial calculation using an iterative `for` loop
- Fibonacci sequence generation using an iterative approach
- Student class for storing student information
- Demonstrates basic Python and object-oriented programming concepts
- Uses only Python's standard library

## Project Structure

    .
    ├── factorial.py
    ├── fibonacci.py
    └── struct.py

## Files

| File | Description |
|------|-------------|
| `factorial.py` | Calculates the factorial of a number using a `for` loop |
| `fibonacci.py` | Generates the Fibonacci sequence using an iterative approach |
| `struct.py` | Defines a `Student` class for storing name, roll number, and marks |

## Requirements

- Python 3.x
- No external dependencies or third-party packages are required

## Installation

### 1. Clone the repository

    git clone <repository-url>

### 2. Navigate to the repository

    cd <repository-name>

### 3. Verify Python installation

    python --version

If your system uses `python3`:

    python3 --version

## Usage

### Run Factorial Program

    python factorial.py

### Run Fibonacci Program

    python fibonacci.py

### Run Student Program

    python struct.py

If your system uses `python3`:

    python3 factorial.py
    python3 fibonacci.py
    python3 struct.py

This project has no external dependencies.
